# Investigation 02 — Nmap TCP Port Scan

## Objective

Analyze network traffic generated by an Nmap TCP port scan and  
determine how open and closed ports can be identified through packet  
analysis.

## Network Information

**Source:** Kali Linux    
**Source IP:** 192.168.1.81

**Destination:** Ubuntu Server    
**Destination IP:** 192.168.1.245

## Methodology

tcpdump was used to capture network traffic while an Nmap scan was  
performed against the Ubuntu server.

The resulting packet capture was opened in Wireshark for analysis.

The following Wireshark display filter was used to identify TCP SYN  
packets that did not contain the ACK flag:

```text  
tcp.flags.syn \== 1 && tcp.flags.ack \== 0
