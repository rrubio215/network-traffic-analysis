# Packet Captures

Packet captures were collected during the network traffic analysis
lab using tcpdump and analyzed using Wireshark.

The original `.pcap` files are not included in this repository because
packet captures can contain network information specific to the lab
environment.

The following captures were created during the project:

- SSH traffic capture
- Nmap port scan capture
- DNS traffic capture
- HTTP traffic capture
- HTTPS traffic capture

The captures were used as evidence during the investigations and
analysis documented in this repository.
